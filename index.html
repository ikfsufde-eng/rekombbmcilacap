Pengenalan Fitur & Cara Instalasi Aplikasi

Selamat Datang di Fuel Star W.A!

Aplikasi pelayanan terpadu Rekomendasi BBM Perikanan Kabupaten Cilacap. Klik tombol "Coba Buka" di bawah untuk mencoba langsung setiap menu:

manage_search

1. Cek Status Permohonan

Pantau progres verifikasi dan penerbitan surat rekomendasi BBM Anda secara real-time menggunakan ID Permohonan.

add_task

2. Pengajuan Baru (Pertalite & Solar)

Buat format pengajuan rekomendasi BBM otomatis dengan validasi KTP/NIK yang akurat, siap dikirim ke WhatsApp Layanan atau disimpan.

storage

3. Data Form (Database Lokal Ber-PIN)

Arsip penyimpanan form pengajuan kapal Anda. Simpan sekali, selanjutnya tinggal pilih dan kirim ulang kapan saja tanpa mengetik dari awal.

description

4. Berkas Digital & Scanner QR

Kelola kelengkapan dokumen kapal pada menu Berkas Digital, atau pindai QR Code surat rekomendasi pada menu Buka Link Berkas.

⚡ Instalasi Cepat Tersedia!

Pasang aplikasi Fuel Star W.A langsung ke layar utama perangkat Anda.

🛠️ Diagnosa & Perbaiki Instalasi

"Perbaiki" hanya membersihkan cache aplikasi. Data Form & PIN Anda tetap aman.

♻️ HP yang Pernah Instal Tapi Gagal / Ikon Rusak

  1. Cari ikon Fuel Star W.A di layar utama atau laci aplikasi. Jika bisa dibuka, aplikasi sudah terpasang (menu ⋮ Chrome akan menampilkan "Buka Fuel Star W.A").
  2. Jika ikon lama rusak / tidak mau terbuka: tekan lama ikonnya, pilih Copot / Uninstall (atau lewat Pengaturan → Aplikasi → Fuel Star W.A).
  3. Buka kembali link aplikasi di Google Chrome (bukan dari dalam WhatsApp), lalu ketuk "Perbaiki & Muat Ulang" di atas.
  4. Tunggu beberapa detik sampai tombol hijau "Instal Sekarang" muncul, atau pilih ⋮ → Instal aplikasi.
  5. Langkah terakhir bila tetap gagal: Chrome ⋮ → Setelan → Setelan situs → Semua situs → pilih situs ini → Hapus & reset. Peringatan: ini ikut menghapus Data Form lokal, jadi catat data penting dulu.

🤖 Pengguna HP Android (Google Chrome)

  1. Buka aplikasi ini menggunakan browser Google Chrome.
  2. Ketuk ikon Titik Tiga (⋮) di pojok kanan atas layar Chrome.
  3. Pilih menu "Tambahkan ke layar utama" (Add to Home screen) atau "Instal aplikasi".
  4. Pilih Instal, maka ikon Fuel Star W.A akan muncul di layar HP Anda.

🍎 Pengguna iPhone / iPad (Safari)

  1. Buka link aplikasi ini di browser Safari.
  2. Ketuk ikon Bagikan (Share) (kotak dengan panah ke atas) di bagian bawah layar.
  3. Geser ke bawah lalu pilih "Tambah ke Layar Utama" (Add to Home Screen).
  4. Ketuk Tambah di pojok kanan atas.

💻 Pengguna Laptop / PC (Chrome / Edge)

  1. Lihat pada bagian kanan kolom alamat URL (Address Bar) di atas.
  2. Klik ikon Instal (Layar dengan panah unduh).
  3. Klik Instal untuk memasang aplikasi di Desktop Anda.
